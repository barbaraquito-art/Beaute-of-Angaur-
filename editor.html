    How to publish

    Make your changes live

    1. Tap Edit next to a page above.
    2. Tap any text to type. Tap a photo to paste a link or upload one. On the Gallery page, use + Add photo and + Add video.
    3. Tap Done, then Download page. The file keeps the page's name, for example gallery.html.
    4. Open Upload files to GitHub, choose that file and tap Commit changes. The live site updates in 1–2 minutes.

    Before uploading, check the file name has no extra "(1)" or "- Copy". If it does, rename it first, or GitHub adds it as a new file instead of replacing the page.
